# Data Warehouse and Analytics Project

Welcome to the **Data Warehouse and Analytics Project** repository.

This project demonstrates the development of a modern data warehouse using **MySQL** for analytical reporting and business intelligence. The solution integrates data from multiple source systems, applies data cleansing and transformation processes, and delivers SQL-based analytics to support business decision-making.

The project is designed as a portfolio project and follows data warehousing best practices, including data integration, dimensional modeling, and analytical query optimization.

---

# Project Objectives

## Data Warehouse Development

### Objective
Build a centralized data warehouse in MySQL that consolidates ERP and CRM data into a unified analytical model.

### Project Requirements

- **Data Sources:** Import data from ERP and CRM systems provided as CSV files.
- **Data Cleaning:** Identify and resolve data quality issues before loading data into the warehouse.
- **Data Integration:** Combine datasets into a single, business-friendly data model optimized for analytics.
- **Data Modeling:** Design fact and dimension tables using a dimensional modeling approach.
- **Scope:** Focus on the latest available dataset; historization is not included in this project.
- **Documentation:** Provide clear documentation of the data model, transformation logic, and project structure.

---

# Analytics & Reporting

### Objective
Develop SQL-based analytics and reporting solutions to generate business insights related to:

- Customer behavior
- Product performance
- Sales trends

The analytics layer is designed to support stakeholders with data-driven decision-making and performance analysis.
